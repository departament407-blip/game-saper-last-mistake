# Медали — графический комплект

Дата: 2026-11-08. Созданы десять самостоятельных SVG для всех существующих ID реестра `src/data/medals.ts`. Это оригинальная векторная графика проекта; внешние изображения и шрифты не используются. Правила выдачи и ID не изменены.

Общий стиль: тканевая пятиугольная колодка с прошивкой и полосами, металлическая скоба и подвес, объёмный кант с насечками, эмалевый центр, рельефная эмблема, блики и небольшие потёртости. Бронза, серебро и золото — визуальное оформление, не новая игровая классификация наград. Размер каждой композиции — `96 × 124`, прозрачный фон; SVG масштабируется без потери резкости.

## Проверенная особенность прежних условий

Фактический `getNewMedalIds()` в `progressionService.ts` уже до этой работы использовал уровни операций вместо названий: `easy → training`, `medium → border`, `hard → forest-road`, `peak → iron-square`, `isEndgame → grand-sweep`. Для `dry-line-medal` и `sunfield-medal` в нём нет триггера выдачи. `fast-small-win` использует `mines <= 18 && seconds <= 60`, то есть допускает ровно 60 секунд. `no-flags-win` проверяет финальное `flagsPlaced === 0`, а не историю постановок.

Эти расхождения сохранены: пользователь отдельно запретил менять правила существующих медалей. Все десять изображений доступны для уже сохранённых наград; корректировка условий/описаний требует отдельного решения.

## Отображение

`MedalRenderer` даёт компактный значок для HUD и карточку для списка наград/дебрифинга. Нативный `<details>/<summary>` раскрывает название и условие по касанию и клавиатуре; desktop также поддерживает наведение. Контейнер HUD не растёт из-за раскрытой подсказки. Новая медаль отмечена золотым контуром и отдельной небольшой искрой; условные римские цифры в UI медалей не отображаются.

Если SVG недоступен, `onerror` показывает встроенный геометрический силуэт медали. Fallback не запрашивает дополнительный файл и сохраняет подпись. `finish` влияет только на оформление и не сохраняется в пользовательском прогрессе.

Проверки: `src/ui/medalRenderer.test.ts` проверяет полноту комплекта, уникальность эмблем, локальность SVG-ссылок, доступность всех ссылочных ID, отсутствие внешних ресурсов/скриптов/текстовых символов в графике, раскрытие описаний, fallback, экранирование текста и выделение новых наград.

`scripts/test-medals.mjs` открывает воспроизводимую галерею через Vite на desktop и телефоне шириной 375 px: проверяет загрузку всех десяти ассетов, выделение новых наград, наведение, клавиатурный фокус, раскрытие касанием и графический fallback при HTTP 404. Скриншоты сохраняются в `.vite/medal-gallery/`; адрес сервера задаётся через `TEST_BASE_URL`.
